# Relux SwiftUI Sample

Демо Relux с Auth в отдельных package products и Notes внутри приложения.
Заметки хранятся в памяти и сбрасываются при перезапуске; поиск работает по заголовку и тексту.

Актуальные команды, требования и архитектура поддерживаются в [English README](README.md) и [PROJECT_GUIDE](PROJECT_GUIDE.md).
См. также [диаграммы](diagrams/README.md) и [учебные упражнения](Docs/LearningExercises.md).

Требования: Xcode 26+, Swift 6.2+; deployment targets — iOS 17+ и macOS 14+.
Постоянное хранение, усиленная очистка сессии и CLI описаны как упражнения, а не реализованные возможности.
